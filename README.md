# AVAND ERP

سیستم یکپارچه فروش، انبار و مالی — Flask + PostgreSQL، رابط کاملا فارسی و ریسپانسیو.

## نصب اولیه (Ubuntu 24.04، یک بار)
```bash
read -rsp "GitHub token: " T; echo
git clone https://x-access-token:$T@github.com/MasoudPourhossein/AVAND-ERP.git /opt/avand && bash /opt/avand/deploy/install.sh
```
- اطلاعات برنامه قبلی (`/var/lib/anbar/anbar.db`) یک بار به PostgreSQL منتقل و کانتینر قبلی خاموش می‌شود؛ یک کپی از فایل قبلی در `/var/lib/avand/app/` می‌ماند.
- برنامه روی `127.0.0.1:8000` است؛ nginx روی میزبان آن را با `https://domain:70` سرو می‌کند.
- پشتیبان و بازیابی: منوی سیستم ← «پشتیبان‌گیری و بازیابی» (پشتیبان دستی، پشتیبان خودکار شبانه، دانلود، آپلود و بازیابی با پشتیبان خودکار قبل از بازیابی). از خط فرمان: `avand-restore FILE.dump`.
- SSL: `avand-ssl` (یا `bash /opt/avand/deploy/ssl.sh`) — گواهی Let's Encrypt، تمدید خودکار (certbot.timer + reload nginx)، TLS 1.2/1.3، HTTP/2، HSTS، انتقال http به https. پورت ۸۰ باید به این سرور فوروارد باشد.

## به‌روزرسانی
```bash
avand-update
```

## مسیرها
| | |
|---|---|
| کد | `/opt/avand` (تنظیمات در `/opt/avand/.env`) |
| دیتابیس | `/var/lib/avand/pg` |
| لوگو، کلید، پشتیبان دستی | `/var/lib/avand/app` |
| پشتیبان خودکار روزانه (۳۰ روز) | `/var/lib/avand/backups` |
| لاگ | `docker logs -f avand-app` |

بازگردانی پشتیبان: `docker exec -i avand-db pg_restore -U avand -d avand -c < file.dump`

## فازها
- **فاز ۱ (این نسخه):** PostgreSQL، اشخاص (مشتری/ویزیتور/تامین‌کننده/کارمند)، چند انبار + انبار پیش‌فرض، گروه کالا، ورود و ویرایش گروهی کالا با اکسل، تغییر گروهی نرخ، خرید و برگشت از خرید، رسید، حواله بین انبار، امانی از هر انبار، تسویه و صدور فاکتور جدا برای هر مشتری ویزیتور، فاکتور فروش مستقیم، صورت‌حساب مشتری/ویزیتور/تامین‌کننده، تراز اشخاص، کدینگ حساب (گروه/کل/معین) و مراکز هزینه.
- **فاز ۱.۱:** فاکتور فروش و خرید استاندارد (تخفیف و مالیات ارزش افزوده هر ردیف، تخفیف نهایی، نحوه پرداخت، سررسید، مشخصات کامل فروشنده و خریدار، مبلغ به حروف، چاپ و PDF رسمی)، برگشت از فروش، ویرایش فاکتور، امانی مستقیم به مشتری، منوی تب‌دار.
- **فاز ۲ (انجام شد):** خزانه — صندوق‌ها، حساب‌های بانکی/پوز، سند دریافت و پرداخت چندردیفی (نقد، پوز، بانک، چک، خرج چک دریافتی) برای همه اشخاص یا هر حساب هزینه/درآمد با مرکز هزینه، علی‌الحساب یا بابت فاکتور، انتقال وجه صندوق↔بانک، چک دریافتی (نزد صندوق، واگذاری به بانک، وصول، برگشتی، عودت، خرج) و چک پرداختی (صادره، پاس، برگشتی، ابطال) با تاریخچه و برگشت عملیات.
- **فاز ۳ (انجام شد):** دفتر کل دوطرفه — سند حسابداری خودکار برای همه اسناد (فروش، برگشت، خرید، رسید، امانی/مرجوعی، خزانه، چک)، سند دستی، دفتر روزنامه، دفتر کل/معین، دفتر تفصیلی (شخص/بانک/صندوق/مرکز هزینه)، تراز آزمایشی ۳ سطحی، سود و زیان، ترازنامه، گزارش مراکز هزینه، صورت‌حساب و تراز اشخاص از دفتر کل، بازسازی اسناد خودکار.
- **بعدی:** ادغام هسته مالی/حقوق Nexus.

## توسعه
```bash
pip install -r requirements.txt
DATABASE_URL=postgresql+psycopg://avand:avand@127.0.0.1/avand AVAND_DATA=./data python3 src/app.py
DATABASE_URL=... AVAND_DATA=/tmp/t python3 -I tests/smoke.py   # پاک کردن و تست کامل دیتابیس تست
```
